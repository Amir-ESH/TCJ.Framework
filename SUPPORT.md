# Support

TCJ Framework is an open-source preview project maintained through GitHub.

## Ask a question

Use GitHub Discussions for usage and design questions when Discussions are enabled. Include the target framework, package or project, relevant configuration, and a minimal code example.

## Report a bug

Use the Bug report issue form. Include:

- the exact TCJ version or commit;
- .NET SDK and operating system;
- minimal reproduction steps;
- expected and actual behavior;
- complete exception details with secrets removed.

## Request a feature

Use the Feature request issue form and explain the problem before proposing an API. Large architectural changes should be discussed before implementation.

## Security issues

Follow [`SECURITY.md`](SECURITY.md). Never report vulnerabilities in a public issue.
