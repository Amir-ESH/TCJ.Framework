# TCJ4007: Value Object member conflicts with generated API

| Property | Value |
| --- | --- |
| ID | `TCJ4007` |
| Category | `TCJ.StrongTypes` |
| Default severity | `Error` |
| Code fix | Unavailable |
| Introduced in | Unshipped |

## Cause

A user-defined member conflicts with the generated primitive Value Object API or introduces a user-defined instance constructor that would create a normal construction path outside `Create` validation.

## Rule description

TCJ reserves `Value`, `IsDefault`, `Create`, `Parse`, `TryParse`, and `ValueObjectJsonConverter`, and owns Value Object instance construction. The generated backing-value constructor is private so successful non-default instances are created through `Create(TValue)`, which invokes application validation first. Default struct instances remain possible and are identified through `IsDefault`.

## How to fix

Remove the user-defined instance constructor or rename the conflicting member. Keep domain validation in the required static `Result Validate(TValue value)` method; generated `Create`, parsing, and JSON deserialization all reuse that validated construction path.

## Examples

### Code with diagnostic

```csharp
[ValueObject<string>]
public readonly partial record struct EmailAddress
{
    public EmailAddress(string value) { } // TCJ4007

    private static Result Validate(string value) => Result.Success();
}
```

### Corrected code

```csharp
[ValueObject<string>]
public readonly partial record struct EmailAddress
{
    private static Result Validate(string value) => Result.Success();
}
```

## Suppression

Suppression is not recommended. Generation is disabled for the conflicting declaration so TCJ does not silently choose between user construction behavior and the validation-first generated contract.

## Known limitations

Applications can always write unrelated static helpers or explicitly work with `default(TValueObject)`. `IsDefault` makes the unavoidable default-struct state observable; the generator only guarantees that its normal successful construction path validates first.

## Compatibility notes

`TCJ4007` is a default `Error`. It protects the generated public API and preserves the validation-first construction path used by `Create`, parsing, and JSON deserialization.
