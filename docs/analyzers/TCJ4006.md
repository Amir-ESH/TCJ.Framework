# TCJ4006: Value Object declaration is invalid

| Property | Value |
| --- | --- |
| ID | `TCJ4006` |
| Category | `TCJ.StrongTypes` |
| Default severity | `Error` |
| Code fix | Unavailable |
| Introduced in | Unshipped |

## Cause

A `ValueObject<TValue>` declaration does not satisfy the v1 primitive Value Object contract. Common causes are a non-partial or unsupported declaration shape, a generic declaration, an unsupported backing type, or a missing/incorrect application-defined validation method.

## Rule description

Primitive Value Objects must be top-level public or internal `readonly partial record struct` declarations backed by `string`, `Guid`, `int`, `long`, or `decimal`. The application must define exactly one static `TCJ.Core.Results.Result Validate(TValue value)` method with the matching backing type. TCJ does not generate domain validation rules.

## How to fix

Use the supported declaration shape and backing type, then add an ordinary application validation method with the exact required signature. Put domain-specific invariant checks inside that method and return `Result.Success()` or `Result.Failure(...)` as appropriate.

## Examples

### Code with diagnostic

```csharp
[ValueObject<string>]
public readonly partial record struct EmailAddress; // TCJ4006: Validate is missing
```

### Corrected code

```csharp
using TCJ.Core.Results;
using TCJ.Core.StrongTypes;

[ValueObject<string>]
public readonly partial record struct EmailAddress
{
    private static Result Validate(string value)
        => string.IsNullOrWhiteSpace(value)
            ? Result.Failure(new ResultError("email.required", "Email is required."))
            : Result.Success();
}
```

## Suppression

Suppression is not recommended. The generator emits no Value Object source when the declaration contract is invalid, so suppressing the diagnostic leaves the expected generated API unavailable.

## Known limitations

v1 supports only one primitive backing value. Composite or arbitrary multi-property Value Objects remain outside the generator contract.

## Compatibility notes

`TCJ4006` is a default `Error`. It prevents invalid declarations from surfacing as downstream generated-code failures and keeps unsupported backing types explicit.
