# TCJ Framework 0.1.0-preview.1

Release date: **2026-08-01**

`0.1.0-preview.1` is the first public preview of TCJ Framework. It establishes the package boundaries, core domain primitives, dependency-registration conventions, EF Core integration, SQL Server support, ASP.NET Core integration, sample application, tests, documentation, and secure release automation.

## Packages

- `TCJ.Core`
- `TCJ.DependencyInjection`
- `TCJ.EntityFrameworkCore`
- `TCJ.EntityFrameworkCore.SqlServer`
- `TCJ.AspNetCore`

## Preview notice

Public APIs may change before `1.0.0`. Pin the exact preview version and review the changelog before upgrading to a later preview.

## Installation

```bash
dotnet add package TCJ.Core --version 0.1.0-preview.1
dotnet add package TCJ.DependencyInjection --version 0.1.0-preview.1
dotnet add package TCJ.EntityFrameworkCore --version 0.1.0-preview.1
dotnet add package TCJ.EntityFrameworkCore.SqlServer --version 0.1.0-preview.1
dotnet add package TCJ.AspNetCore --version 0.1.0-preview.1
```

Install only the modules required by the application. Provider and integration packages bring their required TCJ dependencies transitively.

## Publication status

All five packages were published and listed on NuGet.org. The immutable release state is recorded in `eng/published-release.json`.

## Validation before publication

The `Release preflight` workflow must succeed on `main` before the tag is created. The first publication was run with the package-ID policy set to `available`. Future releases use `existing`.

The release tag is:

```text

```
