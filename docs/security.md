# Security

TCJ Framework treats dependency review, release provenance, SBOM verification, reproducible packages, and responsible vulnerability reporting as part of the release process.

Report suspected vulnerabilities privately by following the repository security policy (repository path: `SECURITY.md`). Do not include credentials, access tokens, private customer data, or exploitable details in a public issue.
