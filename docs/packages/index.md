# Packages

The `0.1.0-preview.5` development line contains seven runtime packages plus the analyzer-only `TCJ.Generators` compile-time tooling package. Each package page describes its installation or consumption model, target framework or tooling boundary, namespaces, primary entry points, and related guides.

- [TCJ.Core](tcj-core.md)
- [TCJ.DependencyInjection](tcj-dependencyinjection.md)
- [TCJ.EntityFrameworkCore](tcj-entityframeworkcore.md)
- [TCJ.EntityFrameworkCore.SqlServer](tcj-entityframeworkcore-sqlserver.md)
- [TCJ.AspNetCore](tcj-aspnetcore.md)
- [TCJ.Messaging](tcj-messaging.md) — transport-neutral messaging contracts and in-memory test adapter
- [TCJ.Messaging.RabbitMQ](tcj-messaging-rabbitmq.md) — production RabbitMQ transport adapter for TCJ Messaging
- [TCJ.Generators](TCJ.Generators.md) — compile-time tooling only
