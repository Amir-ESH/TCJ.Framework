# Code of Conduct

## Our standard

Participants are expected to communicate respectfully, focus criticism on ideas and code, welcome constructive feedback, and avoid harassment, discrimination, personal attacks, or disclosure of another person's private information.

## Scope

This standard applies in repository issues, pull requests, discussions, reviews, and other spaces representing TCJ Framework.

## Enforcement

Report conduct concerns privately to the repository maintainer through an appropriate private GitHub channel. Reports will be reviewed as fairly and confidentially as practical. Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when behavior violates this standard.

## Attribution

This project-specific code of conduct is intentionally concise. It is not a substitute for applicable platform policies or law.
